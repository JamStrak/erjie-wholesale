# 二姐批发小算盘

包包、帽子批发的独立报价工具。先试数量和折扣，算清整单成本与预计利润，再记下客户约定。

**网页版：** https://jamstrak.github.io/erjie-wholesale/

**本机使用：** 双击 `启动小算盘.vbs`。无需打开终端；重复双击会打开已运行的工具，端口被占用时自动换一个可用端口。首次运行需要已安装 Node.js。

## 怎么用

1. 初次打开是“试算练习区”，内置发财包（进价 10 元、批发价 15 元、建议零售价 29 元）和鸭舌帽（进价 8 元、批发价 11 元、建议零售价暂沿用参考值 35 元），两者每件包装均为 0.5 元。默认试算 50 件，可在“商品与进价”自行修改。
2. 准备好了点“开始正式记录”，保留现有商品和价格，清除练习客户与报价；有用记录请先备份。核对实际运费等费用，厂家有满量价再添加采购阶梯，内置案例不预设厂家优惠。
3. 在“客户小本本”记录称呼、默认批发折扣，也能为每件商品约定折前专属单价和单独折扣。专属折前价优先于商品标准价，单商品折扣优先于客户默认折扣。
4. 在“开价模拟器”选商品、客户，默认从 50 件开始。填写折前单价、客户折扣和整单费用，查看折后价、这次让利少赚多少，以及客户按建议零售价全部售完的毛利润。红色表示亏损；“设为折前单价”可把目标利润对应售价作为新基准，从 10 折重新试算。
5. 点“保存这次报价”。历史保留当时的成本和价格，后来修改商品不会改掉旧报价。“复制给客户”只含商品、售价、数量、运费和合计，不含内部备注、进价或利润。
6. 定期在“数据与帮助”下载完整 JSON 备份。换设备、浏览器或清理浏览器前先备份；在新设备选择文件恢复。

## 计算口径

- 折后成交单价 = 给客户的折前批发单价 × 折扣 ÷ 10，四舍五入到分。折前 30 元时，9 折是 27 元、8 折是 24 元；反复调整不会在上次折后价上再打折。
- 让利影响 = 相同数量和费用下，不打折时利润 − 打折后利润，包含手续费变化。
- 客户售完预计毛利 = 数量 × 建议零售价 − 数量 × 折后成交单价 − 客户另付运费。未扣客户自己的包装、运费、平台费、人工、退货损耗，不代表净利润。
- 全部收款 = 数量 × 每件售价 + 客户另付运费。
- 全部成本 = 数量 ×（每件进价 + 每件包装）+ 发货运费 + 本单分摊进货运费 + 其他整单成本 + 收款手续费。
- 手续费按全部收款计算，四舍五入到分；其余金额以整数分计算。
- 预计利润 = 全部收款 − 全部成本；利润率 = 预计利润 ÷ 全部收款。
- 保本单价是按已填费用不亏损的最低分位售价。目标单价按自定利润率计算，不代表市场推荐价。
- 厂家采购阶梯达到数量门槛后，全单所有件使用该进价。比较表沿用当前整单费用；数量变大导致运费增加时要自行更新。
- 税费、人工、退货、损耗等未填写支出不会凭空加入；需要时计入“其他整单成本”。

## 数据与小金库

数据只存在当前浏览器的本地存储，网页代码公开，但录入的客户、成本、报价不会上传 GitHub，也不放在链接中。不提供账号和跨设备自动同步；本地存储和备份不加密。不同网址、浏览器和设备各保存一份，建议固定使用线上链接。

工具不收款、不扣库存、不自动记账。成交后去 [二姐小金库](https://jamstrak.github.io/erjie-vault/) 记录真实收支；两个工具的记录独立。

JSON 恢复会替换当前数据，确认前显示记录数量，保留一次导入前恢复点。报价 CSV 包含成本与利润，只供自己管理。

版本 1.1 兼容旧数据和备份。旧商品未存折前批发价时请手动补填；历史成交价和成本保持原样。旧客户专属成交价转为折前专属价并按 10 折使用。保存报价时若勾选“记为下次的折前专属价”，本次成交价将成为下次的 10 折起点，避免再次叠加优惠。

版本 1.1.1 打开时会更新未经编辑的旧内置商品案例；自己改过的商品、客户和历史报价保持原样。不会给已有的空商品列表重新添加案例。

## 开发维护

无构建、无第三方运行依赖。静态文件可直接部署 GitHub Pages。`npm start` 提供本地服务，`npm run check` 检查语法，`npm test` 检验金额、采购阶梯和数据备份逻辑。入口关系与已验证范围见 `PROJECT_CONTEXT.md`。
